Installing it

1. Download it on the phone

Open this page on the device itself and tap the button above. Downloading on a computer and copying the file over works too.

2. Allow the install

Android asks whether your browser may install apps, because this did not come from the Play Store. Allow it for the browser you downloaded with, then come back to the file.

3. Sign in

Use the account you already have, or make one in the app. Your entries, points, level and cosmetics are all already there.

Worth knowing first

Installed a build from before 18 August 2026?

Uninstall it first. Android only replaces an app when the new file carries the same signature, and those earlier builds were each signed with a one-off key. From this one onwards they share a single release key, so later versions install straight over the top. Nothing you make is kept on the phone, so uninstalling costs you nothing.

Not on Google Play

It is a straight download from this site, which is why Android treats it as an unknown app. The file is built in the open by GitHub Actions from the source in this repository.

Some links open elsewhere

Files - mp4, mp3, images - play inside the app. YouTube, Vimeo, Spotify and SoundCloud have no stream an app may play directly, so those hand off to the official app or your browser instead.
